# Exported iFlows

Put the exported integration package here (Cloud Integration → Design → package **FrischMarkt** → Export), for example:

- `FM_01_Shop_Orders.zip`
- `FM_02_Daily_Reorder.zip`
- `FM_03a_ASN_Inbox.zip`
- `FM_03b_Goods_Receipt.zip`

Exports contain no passwords: credentials stay in the tenant's Security Material and are only referenced by name.
